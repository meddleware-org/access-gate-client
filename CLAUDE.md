# CLAUDE.md — @meddleware/access-gate-client

The one client for the `access_gate` Move package (`meddleware-org/access-gate-sui`). Apps, the
walrus-relay composables and the nft-gate Worker read and build `access_gate` through it. The
gateway challenge/proof wire protocol stays in `@meddleware/nft-gate-client`.

## Invariants

- **Declaration-only build step.** Ships TypeScript source as the runtime (`default` export
  condition) and emits `.d.ts` into `dist/` via `tsconfig.build.json`. `prepublishOnly` builds.
  Do not add a transpile step or point `default` at `dist/`.
- **Id rule.**
  - Builders call `packageId`, the latest **published-at**.
  - Reads, type strings and event queries use `originalId` (or an `nftType` under it).
  - Never mix the two.
- **Exact types.**
  - Every parser compares the normalised full type with `<originalId>::access_gate::<Name>`
    (`isAccessGateType` / `normalizeAccessNftType`).
  - Do not add suffix or regex matching.
  - Keep the look-alike-package tests.
- **No silent truncation.** Owned-object reads page to the end (`listAllOwnedObjects`) and throw
  past `MAX_OWNED_PAGES`.
- **Events decode from BCS.** The layouts in `src/events.ts` mirror the Move event structs field for
  field. Change them in the same release as any event change in `access-gate-sui`.
- **The indexer is display-only.**
  - `listAccessGateEvents` decodes and type-checks indexer rows exactly like full-node events.
  - It falls back to the full node for a first page.
  - Nothing here uses indexer data to authorise.
- **Ids come from `deployments`.**
  - `src/deployments.ts` is generated by `scripts/gen-deployments.mjs` from
    `@meddleware/access-gate-sui`'s `Published.toml` and `deployments.json`.
  - Never edit it by hand. CI runs `check:deployments`.
  - No other file holds a package or object id.
- **Abort table.**
  - `ACCESS_GATE_ABORTS` mirrors the `E_*` constants in `access_gate.move` (codes 1–14).
  - Every builder that touches a gate or consumes passes `platformConfigId` (the on-chain version gate).
  - `abortMessage` only claims aborts located in the `access_gate` module.
- **`@mysten/sui` is the only runtime dependency.**
- **No secrets.** Signers and RPC endpoints are caller-supplied.
- **0BSD licence.**

## Tests

- **`npm test`** — offline unit tests: parsers, paging, events (BCS round-trips, indexer fallback),
  aborts, deployments and type names.
- **`GRPC_TESTNET=1 npm run test:integration`** — live reads against public testnet, using the
  recorded deployment.
