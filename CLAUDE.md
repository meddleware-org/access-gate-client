# CLAUDE.md — @meddleware/access-gate-client

The one client for the `access_gate` Move package (`meddleware-org/access-gate-sui`). Apps, the
walrus-storage-kit composables and the access-gate Worker read and build `access_gate` through it. The
gateway challenge/proof wire protocol stays in `@meddleware/access-gate-gateway-client`.

## Invariants

- **Declaration-only build step.** Ships TypeScript source as the runtime (`default` export
  condition) and emits `.d.ts` into `dist/` via `tsconfig.build.json`. `prepublishOnly` builds.
  Do not add a transpile step or point `default` at `dist/`.
- **Id rule.**
  - Builders call `packageId`, the latest **published-at**.
  - Reads, type strings and event queries use `originalId` (or an `nftType` under it).
  - Never mix the two.
- **Exact types.**
  - Every parser compares the normalised full type with `<originalId>::access_gate::<Name>`
    (`isAccessGateType` / `normalizeAccessNftType`).
  - Do not add suffix or regex matching.
  - Keep the look-alike-package tests.
- **No silent truncation.** Owned-object reads page to the end (`listAllOwnedObjects`) and throw
  past `MAX_OWNED_PAGES`.
- **Parsers fail closed.** Object fields are read with the strict readers in `src/json.ts`; a
  missing or mistyped field makes the parser return `null` (never a default — a missing price is not
  a free gate). IDs and addresses come back normalised, and gate-id filters compare normalised.
- **u64 inputs.** Builders pass every amount through `toU64`: a bigint, or a `number` that is a safe
  integer. An unsafe `number` throws instead of encoding a different amount.
- **Events decode from BCS.** The layouts in `src/events.ts` mirror the Move event structs field for
  field. Change them in the same release as any event change in `access-gate-sui`.
- **The indexer is display-only.**
  - `readIndexerEvents` is the one indexer reader (sealed-storage-client uses it too): https only (loopback
    http allowed), a timeout, a 1 MiB body cap before parsing, and a checked page shape.
  - A **head page** (no `before`) must be fresh: `polledAt` (epoch ms, served by sui-indexer on head pages only)
    present, a safe integer, no older than `STALE_AFTER_MS` (60 s = 4 × the indexer's 15 s poll; override with
    `IndexerSource.staleAfterMs`) by `Date.now()`, and at most `CLOCK_SKEW_TOLERANCE_MS` (5 min) in the future.
    Otherwise `readIndexerEvents` throws and the callers fall back to the full node exactly as for a network
    failure (sui-indexer audit F19). Pages with `before` are immutable history: never checked. The check
    lives here only; sealed-storage-client inherits it through this function.
  - `listAccessGateEvents` decodes and type-checks indexer rows exactly like full-node events.
  - It falls back to the full node for a first page.
  - Nothing here uses indexer data to authorise.
- **Ids come from `deployments`.**
  - `src/deployments.ts` is generated by `scripts/gen-deployments.mjs` from
    `@meddleware/access-gate-sui`'s `Published.toml` and `deployments.json`.
  - Never edit it by hand. CI runs `check:deployments`.
  - No other file holds a package or object id.
- **Authorisation role.** `ownsAccessNft` (with `isUsablePass`) is used to AUTHORISE (the access-gate Worker,
  sealed-storage-ui). They count only usable passes and fail closed on an unknown variant; indexer data is never
  an input.
- **Abort table.**
  - `ACCESS_GATE_ABORTS` mirrors the `E_*` constants in `access_gate.move` (codes 1–16). `tests/aborts.test.ts` compares the table with the `E_*` constants of the pinned
    `@meddleware/access-gate-sui` source, so a new or renumbered constant fails the offline suite.
  - `validateGatePolicy` mirrors `new_gate_policy`'s rule (`E_POLICY_COMBINATION`); `buildCreateGateTx` applies it
    before building. Change it together with the Move rule.
  - Every builder that touches a gate or consumes passes `platformConfigId` (the on-chain version gate).
  - `abortMessage` only claims aborts located in the `access_gate` module.
- **`@mysten/sui` is the only dependency**, as a peer (`^2.33.2`); there are no runtime dependencies.
- **No secrets.** Signers and RPC endpoints are caller-supplied.
- **0BSD licence.**

## Layout and commands

```text
src/
├── index.ts        public re-exports
├── deployments.ts  GENERATED ids per network (subpath `./deployments`)
├── typeNames.ts    full type strings, exact normalised matching
├── types.ts        object, event and structural client types
├── json.ts         strict field readers
├── ownership.ts    paged owned-object reads; access NFTs
├── gates.ts        AdminCaps, Gates, PlatformConfig, PlatformAdminCap
├── events.ts       BCS event decoding, listAccessGateEvents (full node / indexer)
├── aborts.ts       ACCESS_GATE_ABORTS (codes 1–16), abortMessage
└── ptb.ts          transaction builders, gate-policy validator, commission arithmetic
scripts/gen-deployments.mjs   writes/checks src/deployments.ts from @meddleware/access-gate-sui
tests/                        vitest unit tests; tests/integration is live testnet (GRPC_TESTNET=1)
```

## Commands

```bash
npm ci && npm run type-check && npm run lint && npm test   # the core of what the `check` CI job runs
npm run check:deployments                                  # src/deployments.ts matches @meddleware/access-gate-sui (npm run gen:deployments rewrites it)
npm run build                                              # the .d.ts files in dist/ (the only build output)
npm audit --audit-level=high                               # the dependency check (this repo does not use mw-audit-gate)
GRPC_TESTNET=1 npm run test:integration                    # live read-only suite against public testnet; CI runs it weekly
```

Release: bump `version`, push, tag `v<version>`; `npm-publish.yml` publishes via npm trusted publishing.
Changes to `access_gate` structs, events or abort codes in `access-gate-sui` need the matching change here in
the same release.

## Tests

- **`npm test`** — offline unit tests: parsers, paging, events (BCS round-trips, indexer fallback),
  aborts, deployments and type names. `tests/abi-table.test.ts` fails if an exported `build*Tx`
  is missing from the ABI table (`tests/abi-table.ts`) — add every new builder there.
- **`GRPC_TESTNET=1 npm run test:integration`** — live reads against public testnet, using the
  recorded deployment, plus the ABI-drift check: every Move call in the ABI table must exist on
  `publishedAt` (public or entry, same type-parameter and parameter counts, trailing `TxContext`
  excluded) **and the same reference kind and type per parameter** (`EXPECTED_PARAMS` in
  `tests/abi-table.ts`), and `publishedAt` must be the package's latest version.
  `schema-drift.integration.test.ts` compares every struct the parsers read with `tests/schema.ts` and
  decodes a real event of each kind. A weekly workflow (`live-read.yml`) runs both without secrets.

- **SDK reference** (TypeDoc from the shipped `.d.ts`): reads, events, builders, abort table,
  `deployments`.
- **Indexer contract.** `GET /v1/{network}/access-gate/events?kinds&gate&before&limit` returns:
  - `events` — full-node event entries, verbatim, with `bcs` in base64;
  - `cursor`;
  - `indexedFromCheckpoint`;
  - `polledAt` (head pages only; epoch ms of the last successful poll, `null` before any poll) — the client
    treats a missing, null or old value as unavailable (see above).

## Gotchas

- **Public full nodes prune events.** `listEvents` on a quiet package rejects with "requested data below earliest available" instead of returning an empty
  page. The library reports it as `EventHistoryPrunedError` (`asPrunedHistoryError` wraps the node's answer; sealed-storage-client uses the same); the live tests skip on it (`tests/integration/pruned.ts`). The weekly `live-read.yml` run failed three times
  (2026-11-02, 11-09, 11-16); the cause was reproduced on 2026-11-21 and the tests fixed (audit F27).
- **`src/deployments.ts` is generated.** Edit `scripts/gen-deployments.mjs` (its template carries the comments), never the file; `check:deployments` fails on drift.
- **Add every new `build*Tx` to `tests/abi-table.ts`** (and its parameter list to `EXPECTED_PARAMS`), or `tests/abi-table.test.ts` fails.
- **`.github/audit-gate.mjs` does not exist here**, and `mw-audit-gate` is not installed: this repository does not depend on `@meddleware/frontend-config`.
  CI runs `npm audit --audit-level=high` (nine moderate advisories in dev dependencies were listed on 2026-11-21; none high).
- **The ids are the Move package's, not ours to edit.** `0.0.11` of `@meddleware/access-gate-sui` is pinned exactly for that reason.
